Trophe - Privacy Policy

Effective 2026-09-24. Version 1.0.

Trophe is a free food & nutrition API. This policy explains what information Trophe handles when you use the API, and what it does not handle. If you are the operator deploying this API, you are responsible for telling your API users what extra logging your own deployment performs (operator contact details are in the Contact section below).

What Trophe does

Trophe serves food and nutrient data from the USDA FoodData Central database (released under CC0 1.0, public domain) via a local read-only SQLite index. Every response is food or nutrient reference data. No user accounts exist, no sign-up is possible, and no personal profiles are created. The API is read-only: nothing you send is stored. Meal estimates are computed per request and never saved.

What is collected

The API key. Trophe authenticates requests with a single shared key sent in the X-API-Key header. The key is compared in constant time against the TROPHE_API_KEY environment variable on the server. Because one key is shared, a request cannot be tied to a specific person, account, or device. Trophe has no way to know who you are from the key alone.

Request logs. The Trophe application code itself does no request logging. The server process that runs Trophe (for example, uvicorn) may write access logs that include the client's IP address and request path. The operator's intent is that any such logs are kept for no longer than 30 days and then rotated or deleted, and are visible only to the operator for debugging and abuse prevention. (The hosting platform keeps its own platform logs under its own policies, outside the operator's control.)

What is NOT collected

  • No user accounts. There is no registration, no login, no passwords, and no profile data of any kind.
  • No tracking cookies. Trophe is an API, not a website, and sets no cookies.
  • No analytics on users. Trophe does not track who you are, what you look up, or how often. Food searches, nutrient profiles, meal estimates, and comparisons leave no record on the server.
  • No payment data. Trophe is free; no payment information is ever requested or stored.
  • No advertising. No ads are served and no data is collected for advertising.

Data retention

Trophe retains nothing about its users. There is no user-data store to expire or delete. Any operator-kept access logs are intended to be kept no longer than 30 days and then rotated or deleted, as described above.

Security

The API key travels in the X-API-Key request header. Users of a hosted Trophe instance should confirm with the operator that the API is served over HTTPS so the key is not transmitted in clear text. The server stores the expected key in the TROPHE_API_KEY environment variable, never in the codebase or database.

Children's privacy

Trophe collects no personal information from anyone, including children. There are no accounts and no way to submit personal data through the API.

International users

Because Trophe collects no personal data, there is no personal data to transfer, store, or process across borders. If the operator keeps access logs containing IP addresses, the operator is responsible for complying with the applicable rules of the relevant jurisdictions.

Reference data disclaimer

Trophe provides reference data only, not medical or dietary advice. Branded food values are manufacturer self-reported; verify against the package label.
